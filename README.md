## 📌 Featured Projects

### 🩺 [ClinQuery](https://github.com/ShlokCodes-85) — *In Progress*
AI medical report interpreter that turns dense lab reports into plain-language explanations. RAG pipeline over ChromaDB with metadata-scoped retrieval (per-report for patients, per-patient for doctors), MMR retrieval, OCR fallback via Tesseract for scanned documents, and link-based doctor access via signed, patient-controlled JWTs — DPDP Act 2023 compliant.
`React · FastAPI · PostgreSQL · ChromaDB · LangChain · Gemini · PyMuPDF · Tesseract`

### 💳 [Fraud Detection AI](https://github.com/ShlokCodes-85/Fraud_Detection_AI)
End-to-end ML system for real-time transaction monitoring — benchmarks XGBoost, Random Forest, and SVM, with an interactive dashboard for model comparison and live inference.
`Python · Scikit-Learn · XGBoost · Pandas`

### 🎭 VeriFake AI
Deepfake detection using a CNN architecture, trained on a Kaggle dataset of real and deepfake short-form video, deployed for inference.
`Python · CNN · Deep Learning`

### 🛂 [AI Visa Success Advisor](https://github.com/ShlokCodes-85/AI-Visa-Success-Advisor)
Full-stack MERN app with an intelligent chatbot and dynamic form builder for visa documentation — dual chat and structured form modes, built on prompt engineering (system prompts, role definition, few-shot examples) rather than RAG.
`React · FastAPI · Gemini API`
