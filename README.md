## About Me

I'm a **Full Stack AI Engineer** who builds and ships production-grade AI products — not tutorial clones. My work sits at the intersection of applied ML, LLM-powered systems (RAG, agentic reasoning), and full-stack engineering (MERN + FastAPI).

- Currently building **ClinQuery**, a RAG-based medical report interpreter with per-report and per-patient retrieval scoping
- Built a **fraud detection model** benchmarking XGBoost, Random Forest, and SVM
- Shipped a full-stack **AI visa advisor** with dual chat/form modes on the Gemini API
- Built a **deepfake detection model**, trained and deployed on real-vs-synthetic video data
- Comfortable owning the full stack: data pipeline → model/LLM layer → API → frontend → deployment
